# student-record-management-system
Project Description

The Student Record Management System is a C programming mini project used to manage student records using a singly linked list.

The system allows the user to add, delete, display, modify, save, load, and sort student records.

Features
Add a new student record
Automatically assign a unique roll number
Delete a record using roll number
Delete a record using name
Display all student records
Modify student name
Modify student percentage
Save records to student.dat
Load records when the program starts
Sort records by name
Sort records by percentage
Save and exit
Exit without saving

Technologies Used:
C Programming Language
Singly Linked List
Dynamic Memory Allocation
File Handling
Structures
Multiple Source Files
